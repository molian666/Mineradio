# Playlist Mutation Sync Design

## Goal

为所有可管理的真实平台歌单提供删除歌单入口，为歌单详情和 3D 歌单架内容提供移出歌曲入口，并在成功后刷新本地目录、合并歌单和当前视图。

## Capability Matrix

| 平台 | 移出歌曲 | 删除整张歌单 | 合并歌单移出来源歌曲 |
| --- | --- | --- | --- |
| 网易云 | 调用来源平台接口 | 调用平台接口 | 调用网易云接口 |
| 酷狗 | 调用来源平台接口 | 显示按钮，点击提示暂不支持 | 调用酷狗接口 |
| Spotify | 调用来源平台接口 | 调用平台接口 | 调用 Spotify 接口 |
| 汽水 | 调用来源平台接口 | 显示按钮，点击提示暂不支持 | 调用汽水接口 |
| QQ 音乐 | 普通 QQ 歌单按现有能力调用接口 | 调用平台接口 | 只写入本地合并歌单排除记录，不调用 QQ 接口 |

“我的喜欢”、已收藏的他人歌单、虚拟歌单和跨平台合并歌单不显示整张删除按钮；QQ 合并歌单的本地排除记录按账号、来源歌单和歌曲标识持久化，避免重新同步后歌曲立即出现。

## UI and Data Flow

详情面板和 3D 歌单架共用 `deletePlaylistByKey`。按钮显示只判断歌单是否为真实、可管理的自有歌单，不再把平台是否有删除接口作为显示条件；执行函数判断 `playlistDeleteUrl`，缺失时通过 toast 明确提示。

详情面板和 3D 内容框共用 `removeSongFromSourcePlaylist`。合并歌单先通过来源平台和来源歌单 id 定位；QQ 来源走本地排除记录，其余平台调用 adapter 的移除接口。成功后更新当前列表、喜欢状态（如适用）、合并缓存和歌单架。

## Error Handling and Refresh

只有远端返回成功或本地排除记录成功写入后，才移除当前 UI 行或目录记录。登录失效、权限不足、接口不支持和网络错误均保留原数据并显示可读提示。成功删除歌单后刷新平台目录、合并歌单缓存和 3D 歌单架。

## Testing

补充源码行为测试覆盖：不支持平台仍显示删除按钮并给出提示、QQ 合并移除不调用 QQ endpoint、本地排除记录会过滤重新构建的合并歌单；保留现有平台 endpoint、UI 命中、目录刷新和缓存失效回归测试。
